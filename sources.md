# Data sources of Level Time

Level Time ships static game data (flight paths, flight times, ship and zeppelin routes, instance data, dungeon
bosses, map coordinates, speedrun records). Generated data files say in their first lines where they come from and
when they were built. This page lists all the sources.

## 1. Our own data extractor

We collect game data ourselves while playing, with a small developer addon that we use only on our own machines. It is
not part of Level Time and is never published.

- It records what the game client shows us during normal play: creatures (name, level, health, where they were seen,
  experience per kill, what they drop), quests (who starts and ends them, objectives, rewards, experience and money per
  character level, where objectives progress), items, vendors, trainers, flight masters and flight times, dungeon
  entrances, bosses, experience per level and from exploring, and which spells creatures in dungeons cast (from the
  combat log, to verify the spell IDs of the boss and trash mechanics).
- Collection happens only through the official addon API of the game client, on our own characters; other players
  are skipped.
- We use the collected data to build and verify the data files Level Time ships. The measured flight times
  (`Assist/FlightTimesData.lua`) also come from our own flights, recorded with Level Time itself.
- A local tool (`tools/extractor`) exports the collected data to JSON and compares it with our hand-maintained
  dungeon guide, dungeon database and mechanics; it only reports, it never changes a shipped file.

## 2. Public game data from wago.tools

Static client data (DB2 tables) comes from the public database at <https://wago.tools>, per game version (Retail,
Classic Era, Anniversary, WoW Forever). Our generator `tools/flights` (`make flights`) reads the tables and writes:

- flight paths and flight master names (`Assist/FlightPathsData/`, `Assist/FlightNamesData/`)
- ship and zeppelin routes (`Assist/TransportData/`)
- instance resets, group sizes and level ranges (`Assist/InstanceData/<flavor>.lua`)
- dungeon bosses in order (`Assist/BossData/`)
- map coordinates (`Assist/MapCoordsData/`)

Each of these files names the game build it was generated from.

## 3. Speedrun records

The world records shown by the speedrun features come from the public API of <https://www.speedrun.com>
(`tools/records`, `make records`, written to `Speedrun/SpeedrunRecords.lua`).

## Hand-maintained data

`Assist/InstanceData/forever_guide.lua` (WoW Forever dungeon level ranges, entrances and boss levels) is maintained by
hand. It is being checked against, and will be replaced by, data from our own extractor.

`Tracking/ClassQuests.lua` (Classic Era / WoW Forever class quests: level, learned spell IDs, reward item IDs) is
maintained by hand from the class quest pages on warcraft.wiki.gg (Druid, Hunter, Paladin, Rogue, Shaman, Warlock,
Warrior quests); spell and item IDs checked on wowhead classic. Stand 2026-11-14; WoW Forever not checked separately.

`Assist/InstanceData/attunements.lua` (key and attunement quest chains: Shadowforge Key, Seal of Ascension, Skeleton
Key, Molten Core, Onyxia) is maintained by hand. It names only the last quest of each chain; the steps come from the
prerequisites in the dungeon database (section 4). The Skeleton Key chain was missing there and was added by hand to
`dungeon_db.lua` (quests 5533, 5537, 5538, 5801, 5803 Alliance; 838, 964, 5514, 5802, 5804 Horde) from
warcraft.wiki.gg (Araj's Scarab) and the quest series on wowhead classic; quest levels from the wiki, required level
55 only confirmed for Araj's Scarab, giver NPCs 11056/11057 without coordinates. Stand 2026-11-15; all chains are
Classic data and unconfirmed for WoW Forever (marked in game).

## 4. Dungeon database

`Assist/InstanceData/dungeon_db.lua` (`ns.DungeonDB`: dungeon quests, instance NPCs, boss loot, quest objectives) and the boss NPC IDs in
`Assist/InstanceData/boss_npcs.lua` were imported once on 2026-11-14 from WTFPL-licensed sources and are maintained by
hand since. Item qualities come from the DB2 table `ItemSparse` on wago.tools (section 2); WoW Forever loot was
confirmed against the Wowhead WoW Forever dungeon guides (2026-11-14, section 5); the quest assignment of the new Forever dungeons was checked against the same guides (2026-11-16) and the Alcaz Prison quest chains were added by hand.

## 5. Guide research (boss and trash mechanics)

`Assist/InstanceData/mechanics.lua` (`ns.Mechanics`, Classic Era and WoW Forever only) is generated by `tools/mechanics`
(`make mechanics`) from our own guide research in `docs/research/mechanics/*.json` (one file per Classic dungeon or
raid; every file present is read, new instances just add a file). Each file lists bosses, rares and trash with NPC ID
and short tips per ability (spell ID, type, English and German text); the sources used are named in each file's
`sources` field, entries marked `unverified` are less certain. Files whose German texts use
ae/oe/ue/ss instead of umlauts are corrected by an explicit word list in the tool. German clients show the German tip,
all other clients the English one (no French or Spanish tips).

Version per line (LT-56): a line without `version` applies to both flavors (Classic research as the basis for WoW
Forever); `"version": "classic"` keeps it off Forever (spell ID missing in the Forever build or ability changed there),
`"version": "forever"` shows it only on Forever. Hall of Thanes (2026-11-14): NPC and spell IDs, abilities and loot per
boss checked against the Wowhead WoW Forever dungeon guide (facts in our own words). `"verified": true` marks a both-flavor line that a Forever source
confirms (same boss, same spell ID on foreverchanges.pro, checked 2026-11-14); on Forever, unconfirmed lines get a grey
"taken from Classic" hint in the tooltip. `make mechanics ARGS=-spellcheck` checks every Forever line's spell ID
against the newest Forever build's `SpellName` table on wago.tools (section 2). Forever-only dungeons (City of Dalaran,
Excavation Site: Wetlands, Hall of Thanes, Ruins of Lordaeron) are written in our own words from the boss notes on
foreverchanges.pro, NPC IDs from the dungeon database (section 4); these files have no `instanceMapID`.

Wowhead WoW Forever dungeon guides (LT-69, checked 2026-11-14; `https://www.wowhead.com/forever/guide/<dungeon>-dungeon-
overview-location-rewards`, one page per dungeon or wing, linked from the guide "Dungeons Overview"): used as a fact
source for boss and trash NPC IDs, ability spell IDs (a matching line gets `"verified": true`; where Wowhead names a
different spell ID for the same ability of the same boss, the Wowhead ID is taken) and the per-boss loot tables (taken
over into the dungeon database as Forever-confirmed drops). Tips for abilities added from these pages are written in our
own words. The "Dungeon Levels" table of the overview page is the source of the level ranges in `forever_guide.lua`
(widest wing range per map). No Wowhead guide existed for The Drowned City, Krol'dok Stronghold, Alcaz Prison, Blackmaw
Hold, Shaper's Terrace, and for the Scarlet Monastery wings other than the Cathedral.

`Assist/InstanceData/bags.lua` (`ns.BagData`: quests with a bag reward and enemies that drop a bag): quest givers, coordinates and prerequisites imported once on 2026-11-16 from the same WTFPL quest database as section 4, bag names/slots and the seven enemy drops from Wowhead (2026-11-15); maintained by hand since.
