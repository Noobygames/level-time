### Instanzen (aus Module wiring)

- Instance ghost return: `InstanceCopy` remembers the instance left as a ghost (`leftAsGhost`); re-entering it as a ghost is always the same copy (visit moved to the new key if the difficulty differs), because enemy GUIDs are secret in Forever instances and nothing can confirm the copy.

### Datenquellen (aus Data sources)

- Played time: server is the source of truth (`RequestTimePlayed()` -> `TIME_PLAYED_MSG`, second arg = seconds on current level); locally extrapolated. `ChatFrame_DisplayTimePlayed` is wrapped so addon requests don't print to chat; always request via `ns.PlayedTime.Sync()`.
- XP/h = XP / seconds of the scope (`Experience.CalculateRate`, also used for history rows). XP sources: kill XP parsed from the kill message, quest XP from `QUEST_TURNED_IN`, "other" = scope XP minus both. Rested XP: decreases of `GetXPExhaustion()` count as consumed bonus.
- PvE kills: `CHAT_MSG_COMBAT_XP_GAIN` messages matching the localized global `COMBATLOG_XPGAIN_FIRSTPERSON`, turned into a start-anchored Lua pattern that captures the XP amount (rested/group bonus variants match, quest XP doesn't). Meaning: kills that granted XP, including group kills. Secret messages (Retail/Forever in combat/instances) count as a nameless kill when in combat or up to 3 s after it and not near a quest turn-in; their XP is taken from the `Experience.OnGain` deltas around the message (`KillCounter.lua`, decided after 0.6 s).
- PvP kills: honorable kills. `GetPVPSessionStats()` only returns a session/daily total, so `PLAYER_PVP_KILLS_CHANGED` adds the delta to the last seen value (total dropping = daily reset).
- Deaths: `PLAYER_DEAD` (ignored while already dead; stores `/played` total in `character.lastDeathPlayed` for `DeathCounter.GetSecondsSinceDeath`, the hardcore row "No death for"); dead time runs until `PLAYER_ALIVE`/`PLAYER_UNGHOST` with `UnitIsDeadOrGhost` false, and is booked on logout.
- Coverage (`Tracking/Coverage.lua`): `character.coverage = { untracked, lastPlayed, gaps, rollbacks }`; the first `TIME_PLAYED_MSG` after login compares with `lastPlayed` (±45 s = gap/rollback) and sets `currentLevel.partial` (copied into level records). Best-time code uses `Runs.LevelTimes(key, true)` / `run.bestTimes` (no partial levels); PB sums keep them. `Coverage.Get(key)` / `Coverage.Text(fraction)`.
- Journal storage (roadmap 252): `character.<log>` in `LevelTimerStatsDB` is only the inbox (newest entries as tables, all running modules use it; `Journal.INBOX_LIMIT` only matters without archive). Older entries live compact (`Lib/RecordCodec.lua`: one tab-separated line per entry, strings via a per-character dictionary; fields per log in `Journal.LOGS`, append new fields only at the end) in the load-on-demand addon `LevelTimer_Archive/` (only declares SavedVariable `LevelTimerArchiveDB`; logic in `Tracking/JournalArchive.lua`). It is loaded at login when an inbox exceeds `Archive.INBOX_MAX` or when something reads `Journal.GetEntries(key, log)` (history journal tables/charts), then every character keeps the newest `KEEP_RECENT` in the inbox. Read journals only through `Journal.GetEntries` (archive + inbox, oldest first, cached; don't mutate); `Journal.Revision()` drives `TableView` `revision` refreshes; Tests: `C_AddOns.LoadAddOn` in the stub runs the archive `.toc` (`wow.addOnLoads`, `state.addOnsUnavailable`). Archive `.toc` `## Interface` must match `LevelTimer.toc`.
- Journal (`Journal.lua`, `character.killLog`/`deathLog`/`questLog`, archive capped at `Journal.MAX_*`, oldest first; quest names from `C_QuestLog.GetTitleForQuestID` or the title remembered at `QUEST_COMPLETE`): kill entries `{ time, kind, name, level, zone }` come from the same messages as the counters (PvE name = first argument of the XP message; PvP name from `CHAT_MSG_COMBAT_HONOR_GAIN` with `COMBATLOG_HONORGAIN[_NO_RANK]`, log only; the PvP counter stays on the session-total delta). Death entries `{ time, level, zone, killer, spell, environment }`: `DeathCounter` remembers the last damage to the player from `COMBAT_LOG_EVENT_UNFILTERED` (swing/range/spell/periodic/environmental, max `LAST_HIT_MAX_AGE` s old). Retail-API clients (Retail, WoW Forever) block the combat log for addons; there `DeathRecap.lua` (detects `C_DeathRecap`, not the flavor) reads the killing blow (first event, as in Blizzard's recap frame) from `C_DeathRecap.GetRecapEvents()`, retried once via `C_Timer.After` if the recap isn't ready at `PLAYER_DEAD` (`Journal.AddDeath` returns the entry, `Journal.SetDeathCause` fills it later).
- `ChatPatterns.lua` turns global format strings (`COMBATLOG_XPGAIN_FIRSTPERSON`, `LOOT_ITEM_SELF`, ...) into start-anchored patterns plus the argument position of each capture, so reordered placeholders (`%2$d ... %1$s`) map correctly; list more specific formats first for `MatchAny`. `Loot.lua` logs quality >= rare (quality from item info, else from the link color) and guesses the source from the last quest (5 s) or kill (60 s).
- Money (`MoneyCounter.lua`): increases count as income; decreases are spending by the open window (merchant, taxi map, trainer; valid `CLOSE_GRACE` s after closing because flights are paid after the map closes), repairs via a `hooksecurefunc("RepairAllItems")` flag, rest = other. Junk sold by `Merchant.lua` also counts in `moneyJunk`. The stub applies server money changes (repair, selling) in `C_Timer.After`, so tests call `wow.runTimers()`.
- Time breakdown (`TimeBreakdown.lua`, loads before `History.lua` so the level-up flush lands in the history record): counters `combatSeconds`/`taxiSeconds`/`afkSeconds` (priority dead > combat > taxi > AFK, ticked every second, flushed on change/10 s/level-up/logout, getters include pending time); rest = scope seconds minus parts incl. `deadSeconds` (`RestOf`). `Experience.RateSeconds` drops AFK time from XP/h, forecasts and history XP/h when `xpRateWithoutAfk`. `RecentXpRate.lua`: XP/h over the last 15 min from session `xpGained` samples.

### Weitere Module (aus Conventions)

- New journal entries can be observed with `Journal.OnAdd(listener(logName, entry))` (`logName` = `killLog`, `lootLog`, ...). `Alerts.lua` uses it plus `ns.OnLevelStarted` for big on-screen alerts (`LevelTimerAlert`, settings `alert*`, all off by default).
- `Daily.lua`: `character.dailyStats["YYYY-MM-DD"] = { seconds, kills, deaths, xp }`; kills/deaths/xp via `Stats.OnIncrement`, independent of the journal limit (long-term charts). Play time is booked on read (`Daily.GetStats`) and logout and split at midnight. `Daily.StartOfDay`/`DayKey` are the shared day helpers.
- `Instances.lua`: runs of party/raid/scenario instances (`character.currentRun`, finished runs in `instanceLog`); counts via `Stats.OnIncrement`. A run is one instance copy (`InstanceCopy`): leaving pauses its clock (except as a ghost), re-entering the same copy continues it, a reset or another copy ends it; wrong guesses are split (snapshot `run.unconfirmed`) or merged back (`Journal.TakeLastInstanceRun`). `Instances.GetCurrentRun()` (open run, also paused) feeds the window row `showInstanceRun`.
- `InstanceCopy.lua` (Tracking): which copy of an instance the player is in. No instance ID for 5-mans: guessed on enter (unknown, reset seen, or left > 30 min ago = new), confirmed when 2 different enemies (target, mouseover, nameplate) show the same `zoneUID` (5th GUID field), like Nova Instance Tracker; a mismatch fires `OnCorrected`. Resets from `INSTANCE_RESET_SUCCESS`/`_FAILED` in `CHAT_MSG_SYSTEM` (leader only). Per character `instanceVisits[name] = { zoneUID, leftAt }`. Listeners: `OnEnter/OnLeave/OnCorrected/OnConfirmed/OnReset`.
- `InstanceLimit.lua`: new instances per realm in `LevelTimerStatsDB.instanceEntries[realm]` (account-wide, last 24 h); limit 5/h (Retail 10), sliding hour; adds/removes entries from `InstanceCopy` guesses and corrections. Rows `showInstanceLimit`/`showInstancesToday`, warning `warnInstanceLimit` at limit-1 and limit and on `TRANSFER_ABORT_TOO_MANY_INSTANCES`.
- `Classification.lua` remembers enemy classification by name from target, mouseover and nameplates; `KillCounter` looks the kill name up to count `ELITE_KILLS`/`RARE_KILLS` and store `classification` in the kill journal. No combat log needed.
- `NearDeath.lua`: health <= 10 % starts an episode, >= 30 % (hysteresis) counts a near death; dying in between clears it. Cause from `DeathCounter.PeekLastHit()`. Health values may be secret in Retail and are then skipped.

### v2.21 modules

- Quest log XP: `Tracking/QuestLogXp.lua` (`QuestLogXp.Get()` ready/open sums, recounted after QUEST_LOG_UPDATE; `QuestLog.RewardXp`, `Entry.ready`), settings `showQuestLogXp`, `questXpOnBar`.
- `Tracking/XpSources.lua`: exploring (`ERR_ZONE_EXPLORED_XP`, CHAT_MSG_SYSTEM assumed), gathering (XP ≤ 5 s after CHAT_MSG_OPENING, out of combat) and location counters `xpWorld/xpDungeon/xpRaid/xpBattleground` from `Experience.OnGain`; `showXpContext`.
- Kill journal entries carry `xp` and `rested` (`Journal.AddKill(kind, name, classification, xp, rested)`); `Experience.CountToLevel` averages base XP of the last `toLevelSamples` inbox entries (0 = whole level), rested pool counts double.
- Rates: `Experience.RateSeconds(seconds, afk, idle)`; idle (`idleMinutes > 0`, counter `idleSeconds`) removed like AFK. Use `Experience.RecordRateSeconds` / `ScopeRateSeconds` instead of reading the AFK counter; `History.Summarize` returns `ratedIdleSeconds`.
- `History/PersonalRecords.lua`: `PersonalRecords.Offer(id, value)`, account-wide `LevelTimerStatsDB.personalRecords`, announces (`announceRecords`) only when beating an existing value, `once` kinds max once per session; sub-tab Levels > Personal records.
- `History/RestedEstimate.lua`: `character.restSnapshot` at logout, `RestedEstimate.Get(key)` = rested share of bar (1 = one level), compare column, `restedAltNotice`.
- `UI/SessionCompare.lua` (`sessionCompareLogin`) uses `Session.ArchivedAtLogin()`.
- `Tracking/MobXp.lua`: learned base XP per name/mob level/player level (5 samples) from the kill journal (field `mobLevel` via `Classification.LevelOf`), else `MobXp.Formula` (Classic, not Retail); tooltip line `Tooltip.KillsLine` (`tooltipKillsToLevel`).
- `MoneyCounter.lua`: `WINDOWS` table (open/close event, spent + income counter), counters `income*`, `Stats.SPENDING`; daily `moneyIn`/`moneyOut`, `character.money`; `History/Money.lua` (`GetPeriodRecords`, `PeriodStart`, `TotalGold`, `PerHour`); `Format.PlainMoney`. Stat `showIncome`.
- `History/PlayHours.lua`: `character.playHours["W-H"] = { seconds, xp }` (Monday = 1, `ns.Every(5)`, not while AFK); `Charts.CreateHeatmap(grid)`; HistoryCharts kinds column/rank/heatmap/line.
- `Tracking/Reputation.lua`: counter `reputation` (zones, runs too), `character.reputationGains[faction] = { amount, last }`; stat `showReputation`.
- `History/ProgressCurve.lua` (`CharacterPoints`, `Series`), `Charts.CreateLineChart` (`SetSeries(series, formatX, formatY)`).
- `Tracking/DeathPlace.lua`: death journal fields `mapID`, `x`, `y`, `lastWords`; `Assist/DeathMap.lua` (`deathMap`) overlay `LevelTimerDeathMap` on `WorldMapFrame:GetCanvas()`.
- `Assist/InstanceReport.lua` (`announceInstanceReport`) on `InstanceCopy.OnLeave`; `InstanceLimit.GetDailyLimit()` (30, nil Retail; unverified), `GetDayCount()`.
