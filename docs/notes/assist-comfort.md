### Hinweise, Komfort, Warnungen (aus Module wiring)

- `ClassBuffs.lua`: opt-in class reminders (`ClassBuffs.REMINDERS`: class, setting, kind buff/pet/weapon, spell IDs Classic rank 1 + Retail), registered via `BuffReminder.Register`; only if a spell of the group is known (`IsPlayerSpell`), buffs matched by client spell name; options only for the player's class (`ForPlayerClass`, label from spell names via `toggle.text`).
- `BuffReminder.lua`: settings `remindFood` (also at max level inside instances, `anyLevelInInstance`) and `remindCamp` (camp and charged only outside instances, `outdoorsOnly`; class buffs: `inCombat`, `anyLevel`, `remindOnLoss`, expiry remembered while readable because Forever keeps even per-spell aura lookups secret in combat) (WoW Forever camp buff "Lagervorteile", matched by spell ID 1229741; clients without that spell get no reminder) and `remindCharged` (WoW Forever, Skyborne only: `UnitRace` race ID 96, buff "Aufgeladen" spell ID 1270893 from "Himmelssicht" at an elemental convergence; the toggle exists for every Forever character because options are built at load time, the race is checked when reminding) warn (alert + chat, repeated every `reminderInterval` minutes, 1-30, default 5, while the buff is missing) when "Well Fed" is missing while leveling, out of combat and not resting. The buff name comes from `C_Spell.GetSpellName(19705)` in the client's language, auras via `C_UnitAuras.GetAuraDataByIndex` (secret names = unknown, no warning).
- Comfort tab layout: sidebar with categories like Leatrix Plus (`builder.AddSubPage(labelKey)` ... `builder.FinishSubPages()`, keys `COMFORT_PAGE_*`); `AutoAccept.lua` (summon after 10 s, resurrect unless helper in combat/dead, battleground release), `Looting.lua` (fasterLoot on LOOT_READY with auto loot, skipLootConfirm), `ScreenText.lua` (hideErrors: UIErrorsFrame unregisters UI_ERROR_MESSAGE, important ones re-added via AddMessage; hideZoneText via HookScript), `Camera.lua` (cameraDistanceMaxZoomFactor only on toggle), `SkipDialogs.lua` (easyDelete fills DELETE_ITEM_CONFIRM_STRING into the StaticPopup edit box, fasterMovieSkip clicks the cinematic/movie close confirmation on Esc/Space/Enter); `FlightTimer.lua` measures flights itself (TAXIMAP_OPENED current node, TakeTaxiNode hook, landing = PLAYER_CONTROL_GAINED/UnitOnTaxi false), `LevelTimerStatsDB.flightTimes["From > To"]`, shown by `UI/FlightDisplay.lua` (TimerDisplay, Timer tab; TimerDisplay states may carry a `title`, config `formatTime`); `TrainAll.lua` (button next to ClassTrainerTrainButton after ADDON_LOADED Blizzard_TrainerUI, buys every "available" row back to front; `TrainerCache.ServiceType(i)` knows the per-client return position); `Social.lua` (declineSharedQuests wins over autoAcceptShared, blockFriendRequests, acceptFriendInvites with declineGroupInvites skipping trusted players via `Declines.KINDS[].keep`, inviteFromWhisper/inviteKeyword; trusted = `Friends.IsTrusted`: friends, BNet friends, guild), `ChatWindows.lua` (reversible: hideCombatLogTab, hideChatButtons, chatEditBoxTop, chatArrowKeys, noChatFade), `ChatHistory.lua` (restoreChat after short gap, `Session.IsShortGap`), `ChatFilter.lua` (filterDrunkSpam, filterSpellLinks); `OptionsBuilder.AddTextInput({ label, get, set, width })`. Reversible overrides of Blizzard frames go through `Lib/Overrides.lua` (`Overrides.New(read, write)` -> `set(object, enabled, ...)` remembers the original, restores on off; `Overrides.Alpha()`, `Overrides.Parent()`, `Overrides.HiddenParent()`); frames with secure children (stance bar) change only out of combat, caught up on PLAYER_REGEN_ENABLED; muting events: unregister only those `IsEventRegistered` reports (`HideFrames.lua`). Step 4 modules: `ActionBars.lua`, `HideFrames.lua`, `CharacterFrame.lua`, `ClassColors.lua`, `Tooltip.lua`, `MinimapTweaks.lua`; sub page `COMFORT_PAGE_FRAMES` (character frame, unit frames, tooltip, minimap). Read nested Blizzard sub-frames through a type check (`child`/`asTable`), stub frames return a no-op for unknown keys. CVar changes go through `Lib/CVars.lua`: `CVars.Override(name, value, scope)` while a setting is on, `CVars.Restore(name, scope)` when off (no-op without saved original, so a CVar is never touched while its setting is off); originals in `LevelTimerDB.cvarOriginals` (profile meta key) or `character.cvarOriginals` (`CVars.CHARACTER`); non-CVar state stores its original on the character (`lowLevelRaidOriginal`, `chatColorOriginals`); protected CVars only when `InCombatLockdown()` is false. Step 5 modules: `ScreenEffects.lua`, `CombatPlates.lua`, `Sounds.lua` (mute groups with own listfile IDs), `RaidRestrictions.lua`, `AddonList.lua`, `ChatColors.lua`; avoid replacing Blizzard scripts (taint); new comfort features go into the matching category (roadmap 329 lists the Leatrix Plus features still to rebuild, own code only).
- Comfort (Options tab "Comfort", all off by default, `Comfort.IsActive(setting)` = setting on and Shift not held): `Merchant.lua` (MERCHANT_SHOW: `autoRepair` via `RepairAllItems`, guild bank first with `autoRepairGuild` only where `Client.HasGuildBank()` (`CanGuildBankRepair`, `RepairAllItems(true)`; if the guild does not pay in time the character pays the rest, the withdraw limit is not checked); then `autoSellJunk` sells quality 0 items with a sell value via `C_Container`), `QuestAutomation.lua` (QUEST_DETAIL accept (quests shared by a player, `questnpc` is a player, need `autoAcceptShared`; gray via `C_QuestLog.IsQuestTrivial` only in Retail/Forever), QUEST_ACCEPT_CONFIRM `autoAcceptShared`, QUEST_PROGRESS/QUEST_COMPLETE `autoTurnIn` with `RewardChoice` (0/1 choices, else most valuable by sell price if `autoChooseReward`), GOSSIP_SHOW/QUEST_GREETING pick finished then non-trivial quests, `skipGossip` picks the single available option). Test scenarios named `forever_*` load the addon as WoW Forever (interface 16001) in the stub (`SCENARIO` global from the Go runner).
- `Declines.lua`: `Declines.KINDS` (setting, event, decline function, StaticPopup to hide, chat line) for trades, group/guild invites and duels, all off.
- `AggroWarning.lua`: setting `warnAggro`, alert in a group (not solo, not role TANK) when a hostile unit (target, focus, mouseover, nameplates) in combat targets the player and is tanked by them for 1.5 s, max every 5 s (`UnitThreatSituation("player")` alone gave false positives in Forever).
- `ManaCallout.lua`: setting `announceLowMana`, role HEALER in party/raid instances: group message below 25 % (rearm at 40 %, waits while `GroupChat.Locked()`); WoW Forever keeps player mana secret even out of combat, there only "out of mana" on `ERR_OUT_OF_MANA`. `ControlCallout.lua`: `announceControlLoss` (healer CC: readable locType with Blizzard text and seconds; Forever hides locType/displayText/timeRemaining, then a `displayType` 2 entry means "can't heal") and `announceControlOver` (all clear when the loss of control count drops to 0, measured duration). `announceHealerAggro` in `AggroWarning.lua` (healer aggro > 2 s to the group). Healer check `Lib/GroupRole.lua` (`IsHealerInGroupInstance`). Group/guild chat sending goes through `Lib/GroupChat.lua` (`PartyChannel`, `GuildChannel`, `Locked`, `Send`, `IsOwnSender` for echoed addon messages: compares the normalized realm from `GetNormalizedRealmName`, fallback `GetRealmName` without spaces/hyphens).

### Minimap button bar (roadmap 451)

- `Assist/MinimapBar.lua` (`minimapButtonBar`, off by default): scans `Minimap` and `MinimapBackdrop` children, collects shown (`IsShown`) named clickable buttons of typical size (16-48 px) and every shown `LibDBIcon10_*`; layout places only buttons that are still shown and never calls `Show()`; skips `IGNORED_NAMES` (Blizzard minimap frames, own buttons) and `IGNORED_PREFIXES` (map pins). Saves parent, points, scale, strata, level, shown per button and restores all when switched off; never in combat (`pendingCollect`/`pendingRestore` on `PLAYER_REGEN_ENABLED`). Rescans on `ADDON_LOADED` and 1 s after login. Bar and toggle use `BackdropTemplate` (Theme panels). Debug check `minimap` has `buttonBar`, `collectedButtons`, `barExpanded`. Collected buttons get `prepareButton`: button and all child frames (depth 3) above the bar (button = bar level + 2, children above; child strata/levels saved in `saved.children` and restored), alpha forced to 1 (LibDBIcon `showOnMouseover` fades hang on Minimap OnEnter/OnLeave and never run for reparented buttons; `fadeOut` stopped, `SetAlpha` and `fadeOut` OnPlay hooked while collected). Layout is re-applied (never in combat) on bar `OnShow`, expand toggle and after `LibDBIcon-1.0` `Refresh`/`Show`/`SetButtonToPosition` (hooked once; they reposition buttons onto the Minimap). Debug check `451.minimapBar.buttons` dumps per button alpha/effective alpha, mouse state, enabled, strata/level, parent, point, children with levels, `fadeOut` playing.
