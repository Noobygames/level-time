# Notizen: Fenster, Layouts, Theme, Edit-Modus, UX

Wortgetreu aus CLAUDE.md ausgelagert. Vor dem Aendern eines Moduls hier nach dem Dateinamen suchen und nur den passenden Abschnitt lesen.

### Hauptfenster (aus Module wiring und Scopes)

- Timer window background: setting `windowBackground` = `default` (bgAlpha + border) or a key of `TimerWindow.CHROMA_COLORS` (solid green/magenta, no border) for chroma keying in OBS.
- Timer window layout: setting `horizontalLayout` (`/lt bar`) switches between `layoutVertical` (rows below each other) and `layoutHorizontal` (info bar: tabs, time and rows chained left to right on one line, XP bar below); visibility (`compactMode`, stat toggles, XP bar) is shared in `updateVisibility`. The bar width only grows with the texts (`growToFitLine`) and is reset on every apply.
- Timer window size: setting `scale` (`TimerWindow.MIN_SCALE`..`MAX_SCALE`) is applied with `SetScale`, so all content scales; layout math stays at scale 1. The resize grip and the slider both change `scale`; rescaling keeps the top-left corner fixed (`setScaleKeepingTopLeft`) because anchor offsets are measured in the frame's own scale. On login the scale is set before the saved position is restored. Right-click on the window opens the settings.
- UI/UX: `Alerts.Show(message, color, { immediate, sound })` queues (max 4) instead of replacing; `Alerts.Clear()` in tests before a trigger. `ns.STAT_GROUPS`/`ns.STAT_PRESETS`/`ns.ApplyStatPreset` (options: preset buttons via `builder.AddButtonRow`, toggles per group via each stat's `group`); every options page scrolls (`entry.scroll`, window capped at 90 % screen height); `autoInstanceTab`; `historyTab`; `/lt help` prints `L.HELP` line by line; first-start hint `L.INTRO` once (`LevelTimerStatsDB.introShown`).

### Stat-Zeilen und Buttons (aus Data sources)

- Stat lines may declare `available()` (false = client cannot provide it, e.g. near deaths where `UnitHealth` is secret); window, broker and options use `ns.IsStatShown(stat, db)`.
- Localized button labels: `Widgets.SetButtonText(button, text, minWidth)` widens the button to its text.

### Broker (aus Conventions)

- `Broker.lua`: LibDataBroker data object, only if another addon already loaded `LibStub("LibDataBroker-1.1", true)` at login; we do not bundle libraries.
