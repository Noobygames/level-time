### Level Time Goals (Schwesteraddon in StreamGoal/)

- Display name "Level Time Goals" (`## Title`, `ns.DISPLAY_NAME`, `SG_TITLE`, CurseForge project 1744370); technical names stay `StreamGoal` (folder, `.toc`, `StreamGoalDB`, `/sg`, zip `StreamGoal-v<version>.zip`, `SG_*` keys) so installs and saved data keep working.
- Own `.toc` (`StreamGoal/StreamGoal.toc`, folder name = `.toc` name, `## Dependencies: LevelTimer`), SavedVariables `StreamGoalDB` (`{ schemaVersion, nextId, goals, settings }`, exists only from login, filled in `LT.OnLogin`). Level Time exports its namespace as global `LevelTimerAPI` (`Core/LevelTimer.lua`); Stream Goal binds it as `ns.LT` and uses Card, Widgets, TableView, Alerts, Journal, ChatPatterns, Format, `OnLogin`/`OnLevelStarted`/`RegisterEvent`/`SafeCall`. Don't copy those modules; if something is missing, add it to Level Time.
- Texts: `StreamGoal/Locales.lua` merges its `SG_*` keys into `LT.locales`, so `LT.L` and the shared widgets (TableView headers) resolve them in Level Time's language. All four languages, placeholders like Level Time (`tests/streamgoal_locales_test.lua`).
- Files (`.toc` order): `Core.lua` (bindings, DB), `Goals.lua` (model: `Create/Add/Set/Cancel/Active/History/OnChange`, goal = `{ id, kind, character, createdAt, target, start, progress, params, status, finishedAt }`, only the character in `goal.character` progresses it), `Kinds.lua` (kind registry: color, icon, `validate`, `initial`, `title`, `body`; kinds `level`, `kills`, `item`, `bgwin`, `custom` (free text, optional counter; `manual = true` kinds are counted by the player via `Goals.Step`: left/right click on the tracker card, +/- in the window, `/sg count <id> [delta]`; `hasCount` false = done/open only)), `Tracking.lua` (events -> progress: level via `OnLevelStarted`, kills via `Journal.OnAdd`, items via `CHAT_MSG_LOOT`, BG wins via `GetBattlefieldWinner` once per match), `Tracker.lua` (cards stacked in `StreamGoalTracker`, `Widgets.CreateMover`, done alert via `Alerts.Show`), `Manager.lua` (`/sg` window: form, active goals, history `TableView`), `Commands.lua`. A new goal kind = entry in `Kinds.lua`, tracking hook in `Tracking.lua`, form fields in `Manager.lua` (`FORM`), `/sg add` parser in `Commands.lua`, strings, test.
- Tests: scenarios named `streamgoal_*` make `tests/wow_stub.lua` also load the Stream Goal `.toc` with its own namespace (global `streamGoal`; `addon` stays Level Time).
- Installer and packaging: `LoadAddons` finds every `<dir>/<dir>.toc` in a top-level folder; `make install/update` handle all addons (`ARGS="-addons StreamGoal"` to limit), `make package` writes one zip per addon. The Level Time zip/CurseForge package does not contain `StreamGoal/` (`.pkgmeta` ignore + toc-based file list). Release pipeline for Stream Goal (own CurseForge project) is not set up yet.
