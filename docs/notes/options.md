Nur die Datei des Reiters lesen, den man aendert. Ladereihenfolge = Reihenfolge in `LevelTimer.toc`; Reiter und Unterseiten erscheinen in dieser Reihenfolge.

- `Core.lua`: `Builder.New`, Aliase und gemeinsame Bausteine, exportiert als `ns.OptionsCore` (`builder`, `addPage`, `finishPage`, `addSection`, `addSlider`, `addToggles`, `addButton`, `addFooterButton`, `addChooser`, `addHint`, `addSubPage`, `finishSubPages`, `toggle`, `localized`, `advanced`, `requires`, `percent`, `toPercent`, `addVisibilityCycle`, `addFrameScaleSlider`). - `Window.lua`: Fussknoepfe (`addFooterButton`), `builder.Finish()`, `ns.OptionsWindow`, `ns.ShowOptionsPage`, `ns.ToggleOptionsPage`, `ns.ToggleOptions`. Muss zuletzt laden.
- Neue Einstellung: in die Datei des passenden Reiters/der Unterseite; neuer Reiter = neue Datei vor `Window.lua` in der `.toc` (Neustart noetig).

### Layout und Optionsfenster (aus Module wiring)

- Text must fit in every language (fr/es are longer): the options code sizes its toggle columns and panel width from the label widths (`fitWidth`), `HistoryWindow.lua` wraps sub-tabs into extra rows (`layoutSubtabs`) and moves the content down (height = most rows of any group, so tab switches don't jump). Don't use fixed widths for localized text. The test stub records anchors in `frame._points` (`tests/layout_fit_test.lua`).
- `UI/Options/*.lua` is only the content (see "Dateien" below); the tab/control framework is `Lib/OptionsBuilder.lua` (`OptionsBuilder.New({ name, alpha, title })` -> builder with `AddPage`, `FinishPage`, `AddSection`, `AddSlider`, `AddToggles`, `AddButton`, `AddFooterButton`, `AddChooser`, `AddHint`, `Finish`, `Refresh`; for custom widgets `Page()`, `RowY()`, `Advance(h)`, `AddRow`, `AddTooltip`, `OnRefresh`; static `Toggle(label, key, available)`, `Localized(key)`). The tab files alias them as `addPage`, ... and has tabs (`addPage(labelKey)` ... `finishPage()`: General, Statistics, Notifications, Alerts, Stream, Speedrun, Profiles; footer buttons on all tabs via `addFooterButton`; height = longest page) and is built declaratively from helpers (`addSection`, `addSlider`, `addToggles` (entries from `toggle(label, settingKey, available)`; `available() == false` skips the control, e.g. Forever-only), `addButton`, `addChooser` (row of tabs for one setting), `addHint`). Streamer-only options belong on the Stream tab, speedrun options on the Speedrun tab. Every control gets a mouse-over tooltip (`Widgets.AttachTooltip`) with text from `L["<LABEL>_TIP"]` (custom key via `toggle.tip`); a new setting needs its `_TIP` text in all four languages. Checkbox labels belong to the click/tooltip area (`SetHitRectInsets`).; each registers a refresh function, so a new setting is one call with `get(db)`/`set(value)` plus strings.

Every `Add*` control registers in the search index (custom widgets are not searchable). `settingsPage` may be a sub page key (TimerDisplay `config.settingsPage`).
- Tests: `wow.clickOption(labelKey)` clicks uniquely via `<KEY>_TIP`; controls on hidden sub pages update only when shown (partial refresh): call `addon.OptionsWindow.ShowPage(...)` first. Stub returns a no-op function for unknown frame fields; don't store optional data as frame fields. Window height = longest sub page (currently Comfort > Hide).
