- `Assist/FlightMap.lua` (`Read()` -> `{ map, nodes[slot] = { slot, name, key, id, x, y, type }, current }`, `Distance(snapshot, from, to)` hop sum or straight line + hop count, `NodeKey`, `RouteKey`); `Assist/FlightTimes.lua` (`LevelTimerStatsDB.flights[flavor][mapID] = { nodes[nodeKey] = {x,y,name}, routes["a>b"] = { seconds (median), samples (last 5), distance, hops, from, to } }`; nodeKey = nodeID or `"%.3f,%.3f"`; `Lookup(query)` -> `{ seconds, source = measured/data/reverse/estimate, estimated, origin }`, `Fit`, `OwnFactor`, `Factor`, `Learn`, `Record`, `Summary`); order: own > shipped (same flavor) > reverse > distance estimate (offset + perUnit x distance, needs >= 1 measured flight on the map). Old `flightTimes["A > B"]` still read/written. `FlightTimer.Lookup(slot)`; `Assist/FlightTooltip.lua` (`flightTimeTooltip`; hooks `TaxiNodeOnButtonEnter` and `FlightMap_FlightPointPinMixin.OnMouseEnter`). `Client.Flavor()` = folder names (forever/retail/anniversary/classic_era). TimerDisplay states may carry `estimated` (`colors.estimated`, `formatTime(seconds, state)`).
- `make flights` (`tools/flights`, `ARGS="-wow 'D:/Games/World of Warcraft'"` or `WOW_DIR`) reads `LevelTimerStatsDB` from every flavor's SavedVariables (read-only) and writes generated `Assist/FlightTimesData.lua` (`ns.FlightTimesData[flavor][map] = { routes, factor = { offset, perUnit, samples } }`, `[flavor].names`); its fit must stay identical to `FlightTimes.Fit`. Run it before a release to ship the owner's newest measurements.
- Flight paths (roadmap 458): `make flights` also downloads DB2 `TaxiPath`/`TaxiPathNode` from wago.tools (latest build per product: `wow`, `wow_classic_era`, `wow_anniversary`, `wowf` = Forever; `tools/flights/wago.go`), sums 3D waypoint distances per direct leg (skip after teleport flag 1 / continent change; delay at stop flag 2) and writes `Assist/FlightPathsData/<flavor>.lua` (`ns.FlightPathsData = { build, speed = { yardsPerSecond, samples, borrowedFrom }, legs["a>b"] = yards, stops }`; each file returns early in other flavors, so only one table exists). Speed = median of length / (seconds - stops) over measured routes (stored `pathLength`, else direct leg of single-hop routes); Era/TBC borrow Forever's speed (shown estimated), Retail none until own flight. Forever: ~29.8 yd/s constant, no takeoff/landing offset; the game takes the direct leg, not the shortest chain, so multi-hop uses the client's hops (`FlightMap.RouteNodeKeys`). `Assist/FlightPaths.lua` `Measure(keys)`, `ShippedSpeed()`; `FlightTimes.OwnSpeed`/`Speed`, source `PATH` after measured/shipped and before reverse; tooltip shows it like shipped data. `-paths ""` skips the download.

### Ship and zeppelin schedules from game data (roadmap 459)

- Classic transports run on TaxiPath loops (TaxiPathNode flag 2 = stop with `Delay`, 60 s at each dock), not in `TransportAnimation` (that table only has elevators and the Deeprun Tram in Classic). `make flights` writes paths with >= 2 stops for classic_era/anniversary/forever to `Assist/TransportData/<flavor>.lua` (`tools/flights/transports.go`, `ns.TransportData.paths[id] = { { continent, x, y, wait, next } }`, `next` = yards to the next stop around the loop).
- `Assist/TransportPaths.lua`: `Match(route)` maps the learned docks (map, x, y) via `C_Map.GetWorldPosFromMapPos` to stops within `MATCH_YARDS` (both axis orders checked; which order the client returns is unverified, see ManualToCheck 226); `Speed()` = median of loop yards / (learned period - waits) over routes with a period (speed is server data, not in DB2); `Period`, `Travel`, `WaitAtDestination`, `Summary` (in check `440.transport.state` as `paths`).
- `Assist/TransportTimes.lua`: `periodOf` (learned > ROUTES > data), `phaseOf` (own sync, else reverse sync + data travel + wait at its destination), `travelOf` (data, else measured; measured stops at the loading screen). `Record` also creates the reverse route; `LinesFor` hides it until a time is known. `KNOWN_MASTERS` (6 zeppelin master NPC IDs, Wowhead Classic) are assigned to the nearest learned dock by `DockOfMaster`.
- `UI/TransportDisplay.lua` plates show every route short ("Tirisfal Glades: Abfahrt in 1:23"); `UI/TransportWorldMap.lua` (`transportWorldMap`) labels docks on the zone map via `WorldMapFrame:GetCanvas()`.
